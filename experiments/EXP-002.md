# EXP-002 · 原始 patch 与聚类区域的可达 IoU 对照

状态：方案已提出，尚未运行。基线为 [EXP-001](EXP-001.md)，提交 12b464e。

## 研究问题

EXP-001 在 PASCAL-Part 1-shot、fold 0 上观察到：给定真值选择最优聚类区域，A_cluster 为 55.56%。将 64×64 网格上的每个 patch 独立选取，能收回多少缺口？这是对掩码空间表达能力的离线诊断，无法直接预测模型精度增益。

## 固定条件与计算

1. 复用 EXP-001 的 2500 对 manifest、31 类、查询真值、ignore 规则、1024×1024 评测网格和最近邻映射。只需现有数据与 CPU。
2. 给每个原始 patch 分配唯一 ID。在有效像素上按 patch 前景纯度排序，扫描前缀求每对的最优 IoU，记为 A_patch。复用 EXP-001 的上界算法，逐对对齐 A_cluster。
3. 逐对检查 A_patch ≥ A_cluster（浮点容差除外）；检查网格、清单以及 A_cluster 按原口径汇总能重现 55.56%。保留每对 TP/FP/FN，分别报告按类累计交并后宏平均、逐对差值分布。宏平均来自逐对最优解，不等于直接优化宏平均。
4. 报告总体、各类的 A_patch、A_cluster、网格缺口 1−A_patch 和合并缺口 A_patch−A_cluster。重点对照羊尾、猫脖子、牛脖子、鸟翼与鸟躯干。展示相同查询的真值、最优 patch 与最优聚类并集。

## 判读与交付

按 EXP-001 预设，用相同宏平均口径计算 (1−A_patch)/(1−A_cluster)。若超过 0.5，推翻“聚类合并解释大部分原始区域缺口”；若低于 0.5，优先检验部件聚类；接近一半时结合类别差异解释。结论限于 fold 0。提交可复跑命令、逐对表、类别表及简短报告，并区分离线上界与真实预测。
